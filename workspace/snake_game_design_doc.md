# 贪吃蛇游戏设计文档

## 1. 项目概述

### 1.1 项目简介
本项目是一个基于Python和Pygame库开发的经典贪吃蛇游戏。玩家通过键盘控制蛇的移动方向，目标是吃掉随机出现的红色食物来增长蛇身长度，同时避免撞墙或撞到自己。

### 1.2 开发环境
- **编程语言**: Python 3.x
- **图形库**: Pygame
- **依赖库**: pygame, time, random

### 1.3 运行要求
- 已安装Python 3.x
- 已安装Pygame库：`pip install pygame`

## 3. 核心功能模块

### 3.1 全局常量配置

```python
# 窗口尺寸
WIDTH = 800           # 窗口宽度
HEIGHT = 600          # 窗口高度

# 游戏参数
SNAKE_BLOCK = 10      # 蛇身方块大小（像素）
SNAKE_SPEED = 15      # 蛇的移动速度（FPS）

# 颜色定义
WHITE = (255, 255, 255)  # 背景色
BLACK = (0, 0, 0)        # 游戏区域背景
RED = (213, 50, 80)      # 食物颜色
GREEN = (0, 255, 0)      # 蛇身颜色
BLUE = (50, 153, 213)    # 分数文字颜色
```

### 3.2 主要函数

#### 3.2.1 your_score(score)
- **功能**: 在屏幕左上角显示当前得分
- **参数**: score - 分数值
- **返回值**: 无
- **实现要点**: 使用SysFont渲染文字，并绘制到指定位置

#### 3.2.2 our_snake(snake_block, snake_list)
- **功能**: 绘制蛇的身体
- **参数**: 
  - snake_block - 蛇身方块大小
  - snake_list - 蛇身坐标列表
- **返回值**: 无
- **实现要点**: 遍历坐标列表，为每个节点绘制绿色矩形

#### 3.2.3 message(msg, color)
- **功能**: 在屏幕中央显示消息
- **参数**: 
  - msg - 消息文本
  - color - 文字颜色
- **返回值**: 无
- **实现要点**: 将文字渲染到屏幕中央位置

#### 3.2.4 gameLoop()
- **功能**: 游戏主循环函数
- **参数**: 无
- **返回值**: 无
- **实现要点**: 
  - 管理游戏状态
  - 处理用户输入
  - 更新游戏逻辑
  - 渲染画面

## 4. 游戏逻辑流程

### 4.1 游戏状态图
```
开始游戏
    ↓
游戏进行中 ←→ [按方向键改变移动方向]
    ↓
   [检测碰撞]
    ↓
   [撞墙/撞自己] → 游戏结束
    ↓
显示结束画面
    ↓
 [按Q退出/按C重新开始]
```

### 4.2 主循环流程

```
gameLoop()
    │
    ├─ 1. 初始化游戏变量
    │   - 蛇的初始位置（屏幕中心）
    │   - 蛇身列表
    │   - 食物位置（随机生成）
    │
    ├─ 2. 进入主循环
    │   │
    │   ├─ 2.1 处理游戏结束状态
    │   │   - 显示游戏结束消息
    │   │   - 等待用户选择（Q退出/C继续）
    │   │
    │   ├─ 2.2 处理用户输入
    │   │   - QUIT事件 → 退出游戏
    │   │   - 方向键 → 更新移动方向
    │   │
    │   ├─ 2.3 更新蛇的位置
    │   │   - 根据移动方向更新坐标
    │   │
    │   ├─ 2.4 碰撞检测
    │   │   - 检测是否撞墙
    │   │   - 检测是否撞到自己
    │   │
    │   ├─ 2.5 更新蛇身
    │   │   - 添加新头部
    │   │   - 删除尾部（如果未吃到食物）
    │   │
    │   ├─ 2.6 检测吃食物
    │   │   - 蛇头与食物重合 → 增加长度、生成新食物
    │   │
    │   └─ 2.7 渲染画面
    │       - 清空屏幕
    │       - 绘制食物、蛇、分数
    │       - 更新显示
    │
    └─ 3. 退出游戏
```

## 5. 核心算法

### 5.1 碰撞检测算法

#### 5.1.1 撞墙检测
```python
if x1 >= WIDTH or x1 < 0 or y1 >= HEIGHT or y1 < 0:
    game_close = True
```
- 检查蛇头坐标是否超出窗口边界
- 超出则设置游戏结束标志

#### 5.1.2 自身碰撞检测
```python
for x in snake_List[:-1]:
    if x == snake_Head:
        game_close = True
```
- 遍历蛇身（除头部外的所有节点）
- 检查头部坐标是否与身体任何节点重合
- 重合则设置游戏结束标志

### 5.2 食物生成算法
```python
foodx = round(random.randrange(0, WIDTH - SNAKE_BLOCK) / 10.0) * 10.0
foody = round(random.randrange(0, HEIGHT - SNAKE_BLOCK) / 10.0) * 10.0
```
- 在窗口范围内随机生成位置
- 使用10.0对齐确保与网格系统匹配
- 确保食物不会生成在窗口边界外

### 5.3 蛇身移动算法
```python
# 添加新头部
snake_Head = [x1, y1]
snake_List.append(snake_Head)

# 删除尾部（如果未吃到食物）
if len(snake_List) > Length_of_snake:
    del snake_List[0]
```
- 每次移动在当前头部位置添加新节点
- 如果蛇身超过当前长度，删除尾部节点
- 通过队列结构实现移动效果

## 6. 操作说明

### 6.1 游戏控制

| 按键 | 功能 |
|------|------|
| ↑ | 向上移动 |
| ↓ | 向下移动 |
| ← | 向左移动 |
| → | 向右移动 |
| Q | 退出游戏（游戏结束画面） |
| C | 重新开始游戏（游戏结束画面） |

### 6.2 游戏规则
1. 蛇初始位于屏幕中央，长度为1个方块
2. 按方向键控制蛇的移动方向
3. 吃到红色食物，蛇身长度+1，得分+1
4. 撞墙或撞到自己，游戏结束
5. 游戏结束后可选择重新开始或退出

## 8. 性能优化

### 8.1 帧率控制
- 使用 `clock.tick(SNAKE_SPEED)` 控制游戏帧率为15FPS
- 保证游戏流畅度和适当难度

### 8.2 渲染优化
- 只在每次循环结束时调用 `pygame.display.update()` 一次
- 避免频繁的屏幕刷新导致性能问题
